# Segurança

Os modelos desta galeria acabam em facturas de empresas reais. Se encontrares uma forma de:

- um modelo esconder, alterar ou imitar elementos fiscais (número, NIF, ATCUD, QR da AGT, menção do programa certificado);
- um modelo meter dados de pagamento, contactos ou ligações que não vêm da empresa;
- passar as verificações da CI (`packages/invoice/scripts/check-templates.tsx`, `src/core/safety.ts`) com conteúdo que devia ser recusado;
- executar código fora do modelo durante a compilação;

**não abras um issue público.** Usa "Report a vulnerability" no separador Security deste repositório - o relatório fica privado entre ti e a equipa.

Respondemos em 72 horas.
